Lima arah desain untuk Mate Engine Android

Setiap opsi di bawah memakai data nyata dari aplikasi yang sudah berjalan: enam tab, kartu status, slider ukuran, gelembung chat, dan ikon aplikasi. Pilih satu, lalu saya kerjakan seluruh aplikasi mengikuti arah itu.

UI bahasa Indonesia Material 3 / Jetpack Compose Adaptif ponsel + jendela lebar Pratinjau = mockup CSS, bukan tangkapan layar APK
Cara memilih:

Balas dengan nomor opsinya, misalnya “ACC opsi 2”, atau gabungan seperti “opsi 1, tapi ikon dari opsi 4”. Setelah ACC saya tulis token warna, bentuk, dan motion resmi di satu berkas tema, lalu menerapkannya ke semua layar — bukan hanya layar contoh di bawah.

Tipografi

Plus Jakarta Sans (judul) + system sans (isi). Skala 24/16/13, judul semi-bold, angka tabular untuk FPS.

Bentuk & gerak

Radius 20–28px, tombol pil penuh. Pegas: stiffness 380, damping 0.72 — overshoot tipis saat kartu muncul.

Ikon aplikasi

Adaptive icon: latar gradien cyan, siluet kepala+rambut sebagai foreground di dalam safe zone 66dp, plus layer monokrom karena Android 16 menurunkan ikon tema otomatis dari launcher icon.

Paling aman. Semua komponen sudah tersedia di Compose; saya tidak perlu menulis ulang widget apa pun. Cocok bila kamu ingin aplikasi ini terasa “resmi”.

Tipografi

Baloo 2 / Nunito untuk judul (bulat), system sans untuk isi. Hindari font tipis — kontras rendah merusak efek clay.

Bentuk & gerak

Radius 26–28px, bayangan dua lapis. Tekan = mengecil ke 0.96 dengan pegas ringan (stiffness 300, damping 0.6).

Ikon aplikasi

Squircle mint dengan highlight bawah-dalam, tanda tebal di tengah. Versi tema = siluet datar satu warna.

Paling cocok dengan tema waifu. Risikonya: kalau semua kartu memakai bayangan tebal, layar panjang jadi berat. Saya akan batasi efek clay pada kartu utama saja.

Tipografi

Space Grotesk / Chakra Petch untuk judul; isi memakai sans netral agar tetap terbaca di latar gelap.

Bentuk & gerak

Radius 14–16px. Glow hanya pada elemen aktif; denyut 2 detik saat menunggu balasan chat.

Ikon aplikasi

Gradien tiga warna magenta→ungu→cyan dengan tanda putih tajam. Versi monokrom wajib: gradien tidak selamat saat difilter jadi satu warna.

Paling dramatis. Karena aplikasi ini sering dipakai sore–malam sambil kerja, tema gelap total bisa melelahkan; saya sarankan versi ini dengan mode terang pilihan.
