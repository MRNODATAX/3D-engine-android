Mate Engine Android 0.1.0

Tangkapan layar APK yang benar-benar dijalankan

Galeri ini memuat hasil adb exec-out screencap dari APK debug yang dipasang di emulator Android 34 (profil Pixel 6) di GitHub Actions. Data model diisi dari berkas vrm1-twist-sample.vrm berlisensi redistribusi lewat hook debug, sehingga yang terlihat adalah aplikasi asli yang membaca metadata VRM asli.

APK debug 0.1.8 (8) Unduh APK uji v0.1.8-test Android 14 · API 34 · x86_64 1080 × 2400 · 420 dpi Perangkat fisik belum diuji

Bukti skala: dua angka, satu perbandingan

Slider "Tinggi avatar di layar" sekarang berarti persentase tinggi layar. Angka pada kedua gambar di atas berasal dari aplikasi yang sama, hanya berbeda nilai scale: 100% memenuhi layar, 40% menjadi kecil di sudut. Sebelum perbaikan, satu nilai dipakai dua kali (lebar jendela dan skala model) sehingga rentangnya menyusut jadi seperempat.

Yang dibuktikan galeri ini

  • Aplikasi terpasang dan berjalan di Android 14 tanpa crash.
  • Tab Chat tampil dengan status kunci yang jujur: belum ada kunci berarti belum bisa mengirim.
  • Izin overlay, notifikasi, dan pembatasan baterai terbaca dari sistem.
  • Metadata VRM asli terbaca dan ditampilkan.
  • Layanan overlay dapat dijalankan dan dilaporkan statusnya.
  • Navigasi, tema, dan tata letak lebar berfungsi.

Urutan pengambilan

  • Pasang APK debug, izinkan overlay, isi data contoh lewat hook debug.
  • Ambil 5 halaman aplikasi (Beranda, Avatar, Animasi, Diagnosa, Pengaturan).
  • Tekan tombol Jalankan avatar seperti pengguna, verifikasi service lewat dumpsys, tekan Home, lalu tangkap overlay.
  • Terakhir: tema gelap dan tata letak lanskap.

Yang belum dibuktikan

  • Perilaku pada HP fisik dan ROM produsen (HyperOS, ColorOS, One UI, Funtouch).
  • Kualitas render pada GPU ponsel; emulator memakai renderer perangkat lunak (SwiftShader).
  • Ketahanan layanan saat layar mati atau Recent Apps dibersihkan.
  • Interaksi drag pada layar sentuh nyata.
  • Kualitas animasi pada perangkat keras sungguhan; emulator memakai SwiftShader sehingga FPS rendah.

Cara memperbarui gambar

  • Jalankan workflow Screenshots di GitHub Actions.
  • Skrip scripts/capture-screenshots.sh memasang APK debug dan mengambil tangkapan layar.
  • Hasilnya di-commit otomatis ke docs/screenshots/.
